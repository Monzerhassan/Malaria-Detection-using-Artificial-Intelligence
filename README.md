# 🦠 Malaria Detection using Artificial Intelligence

## 📌 Overview
This project aims to build an intelligent system for detecting malaria using artificial intelligence and machine learning techniques. The model analyzes microscopic blood smear images and classifies them as infected or uninfected.

---

## 🎯 Objectives
- Early detection of malaria
- Reduce reliance on manual diagnosis
- Improve accuracy and speed of detection
- Assist healthcare professionals

---

## ⚙️ How It Works
1. The user uploads a blood smear image.
2. The system preprocesses the image.
3. A trained deep learning model analyzes the image.
4. The image is classified into:
   - Parasitized (Infected)
   - Uninfected
5. The result is displayed with a confidence score.

---

## 🧰 Technologies Used
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Tkinter (for GUI)

---

## 🧪 Dataset
The model is trained on microscopic images of blood cells:
- Parasitized cells
- Uninfected cells
